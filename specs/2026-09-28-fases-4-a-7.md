# Fases 4 a 7 — sessão retomável, GitHub e polish

## Intenção

O CoreDev passa a cumprir a promessa central do ROADMAP: fechar o app no meio de uma
conversa com o Claude Code e, ao reabrir, encontrar o mesmo layout, o mesmo scrollback,
o mesmo diretório e o `claude` já rodando de novo. Junto vem o terceiro pilar — um painel
de GitHub que lista PRs e issues do repositório do projeto e faz checkout de PR no terminal
visível — e o polish mínimo para o app ser usável no dia a dia (paleta de comandos, fixar
projeto na sidebar).

Duas decisões revogam o ROADMAP, ambas registradas em `decisions/`: a persistência usa
arquivos JSON no `userData` em vez de `better-sqlite3` (§3.4, §4), e o GitHub usa o `gh` CLI
em vez de device flow OAuth + Octokit (§6).

## Critério de aceite

1. Persistência de layout (Fase 4)
   - Montar 3 panes em 2 projetos, fechar o app pelo botão da janela, reabrir.
   - Esperado: mesmo layout, mesmos projetos, mesmo pane focado.

2. Restauração de terminal (Fase 5) — o momento em que o produto passa a existir
   - Abrir um projeto, deixar o `claude` rodando, trocar algumas mensagens, fechar o app, reabrir.
   - Esperado: o scrollback anterior aparece, seguido de um separador visual de sessão,
     o `cwd` é o do projeto e o `claude` já está rodando (sessão nova).

3. `cwd` rastreado
   - Num pane, `cd` para um subdiretório, fechar e reabrir o app.
   - Esperado: o terminal restaurado abre no subdiretório (shell com OSC 7); sem OSC 7,
     volta para o `cwd` inicial do pane sem erro.

4. GitHub (Fase 6)
   - Num projeto com remote `origin` no GitHub, abrir um pane de GitHub.
   - Esperado: lista de PRs abertos com autor, branch e status de CI; alternar para issues;
     clicar em "checkout" de um PR escreve `gh pr checkout <n>` no terminal daquele projeto.
   - Sem `gh` instalado ou sem `gh auth login`: mensagem acionável, nunca um painel vazio mudo.

5. Paleta de comandos (Fase 7 parcial)
   - `Ctrl/Cmd+K` abre a paleta, digitar filtra, Enter executa.
   - Esperado: cobre adicionar projeto, split horizontal/vertical, fechar pane, zoom,
     abrir pane de GitHub e focar cada projeto aberto.

6. Fixar projeto na sidebar
   - Fixar um projeto, adicionar outro, reabrir o app.
   - Esperado: o fixado continua no topo, com indicador visual.

7. `npm run typecheck && npm test` verdes.

## Fora de escopo

- `better-sqlite3`, schema SQL e runner de migrações (revogado, ver `decisions/`).
- Device flow OAuth, `safeStorage`, Octokit, cache com ETag (revogado, ver `decisions/`).
- Assinatura de código (Authenticode / notarização Apple) e auto-update via `electron-updater`:
  exigem certificado e conta paga, não cabem nesta sessão.
- Tela de preferências, export/import de configuração, telemetria de crash.
- Ações de escrita no GitHub (comentar, aprovar, merge) — backlog pós-MVP do ROADMAP.
- Modificar o rc file do shell do usuário para instalar OSC 7 (risco R8): o app degrada
  sem isso e não pede nada.
